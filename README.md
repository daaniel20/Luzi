# LUZI

לוח זמנים יומי לילדים. הציר אנכי, מלמעלה למטה, ומתחיל כברירת מחדל ב־06:30 לאורך יממה. אפשר לשנות את טווח השעות, את רזולוציית המשבצות, לייצא את הלוח כתמונה, ולגרור משימות שנצמדות לרזולוציה.

העיצוב רגוע: רקע אפור־תכלת, וקוביות בורוד, כתום וירוק. הלוח נשמר בדפדפן לפי היום.

## הרצה מקומית

```bash
npm install
npm run dev -- -p 43123
```

ואז לפתוח [http://127.0.0.1:43123](http://127.0.0.1:43123).

## איך משתמשים

- גוררים משימה מבנק המשימות אל הציר האנכי. ברירת המחדל היא 06:30 עד 06:30 למחרת.
- כפתור «טווח שעות» משנה אילו שעות מוצגות, למשל רק צהריים.
- כפתורי הפלוס והמינוס משנים את הרזולוציה: 60, 30, 15, 10 או 5 דקות.
- כפתור «תמונה» מוריד את הלוח כקובץ PNG.
- מושכים את הקצה הימני או השמאלי כדי להאריך או לקצר, בקפיצות של 15 דקות.
- ה־X על משימה בלוח מוריד אותה מהיום. אפשר גם לגרור אותה בחזרה אל בנק המשימות.
- «חדשה» מוסיפה סוג משימה: שם, צבע ואימוג׳י.
- הכותרת למעלה. מתחתיה הציר ובנק המשימות זה לצד זה. גוררים את הפס שביניהם כדי לשנות את הרוחב.
- «חדשה» מוסיפה משימה לבנק. עיפרון על קובייה משנה שם, צבע ואימוג׳י. שם יכול להכיל עד 32 תווים.
- גוררים קובייה בתוך הבנק כדי לשנות את הסדר. גרירה אל הציר עדיין שמה אותה על הלוח.
- ה־× על קובייה מוחק את סוג המשימה מהבנק.
- «תמונה» או «שליחה» נמצא למעלה. באייפד זה פותח את דף השיתוף, כולל הודעות.
