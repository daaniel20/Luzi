# LUZI

לוח זמנים יומי לילדים. גוררים קוביית משימה אל ציר השעות, והיא נצמדת לרבע השעה הקרוב. אפשר למתוח את הקצוות, למחוק אל הפח, ולהוסיף סוגי משימות עם צבע ואימוג׳י.

העיצוב רגוע: רקע אפור־תכלת, וקוביות בורוד, כתום וירוק. הלוח נשמר בדפדפן לפי היום.

## הרצה מקומית

```bash
npm install
npm run dev -- -p 43123
```

ואז לפתוח [http://127.0.0.1:43123](http://127.0.0.1:43123).

## איך משתמשים

- גוררים משימה מבנק המשימות אל ציר היום (07:00–20:00).
- מושכים את הקצה הימני או השמאלי כדי להאריך או לקצר, בקפיצות של 15 דקות.
- גוררים משימה מהלוח אל הפח, או בחזרה אל בנק המשימות, כדי להוריד אותה.
- «חדשה» מוסיפה סוג משימה: שם, צבע ואימוג׳י.
- ה־× על קובייה מוחק את סוג המשימה מהבנק.
